## 分时图  试盘 测试抛压

试盘三要素：

1. 三倍量以上
   目的是防止主力对到形成的量
2. 带上影线阳线(涨停板，假阴线,阴线不是试盘)
   试盘形态两个特征

- 拉高横盘，最终收阳线
- 拉高动作在一点半之前，主力才能有效测试抛压
  ![img_11.png](img_11.png)

3. 突破前期趋势：突破20日趋势以上
   ![img.png](img.png)

试盘当天不上车，试盘为了测试抛压
如何评测抛压大：最高价和收盘价大于3个点则认为抛压大
![img_2.png](img_2.png)

试盘生命线：试盘当天收盘价
![img_4.png](img_4.png)
生命线作用：股价站上生命线则可以上车，股价未突破生命线则不能上车，突破是指收盘价高于生命线
